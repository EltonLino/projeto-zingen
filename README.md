# 🎤 Zingen - Landing Page

O **Zingen** é uma landing page de marketing responsiva e de alta performance desenvolvida para apresentar um aplicativo fictício de Karaokê baseado em inteligência artificial. 

Este projeto foi desenvolvido como um desafio prático durante a formação **Full-Stack da Rocketseat**, com o objetivo de consolidar conceitos avançados de estruturação de layout, estilização moderna e adaptabilidade para múltiplos dispositivos.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído puramente com tecnologias web nativas, explorando recursos modernos do ecossistema front-end:

- **HTML5**: Estruturação semântica e acessível do conteúdo.
- **CSS3**: Estilização avançada utilizando conceitos como:
  - **CSS Nesting**: Organização hierárquica e limpa do código de estilos.
  - **Custom Properties (Variáveis CSS)**: Gerenciamento eficiente da paleta de cores, tipografia e espaçamentos.
  - **Flexbox & CSS Grid**: Para a criação de layouts complexos e dinâmicos.
  - **Responsividade**: Uso estratégico de Media Queries e unidades de medida relativas para garantir uma experiência fluida do mobile ao desktop.
  - **Animações e Transições**: Efeitos visuais sutis para melhorar a interatividade e a experiência do usuário (UX).

---

## 🎨 Funcionalidades e Seções da Página

1. **Cabeçalho (Header)**: Navegação simplificada e botão de chamada para ação (CTA).
2. **Hero Section**: Apresentação principal do aplicativo com título impactante, descrição e botões de download.
3. **Recursos / Funcionalidades**: Detalhes sobre a Inteligência Artificial do app, catálogo de músicas e recursos de gravação.
4. **Planos de Assinatura**: Grid comparativo exibindo os preços e benefícios dos planos Individual e Família.
5. **Rodapé (Footer)**: Links institucionais, redes sociais e direitos autorais.
